# LeetCode 1356 - 解题思路

## 题目
[根据数字二进制下 1 的数目排序](https://leetcode.cn/problems/sort-integers-by-the-number-of-1-bits/)

## 核心技巧：多关键字排序

### 关键代码

```python
sorted(arr, key=lambda x: (self.count_bits1(x), x))
```

### 原理详解

#### 1. lambda 返回一个元组

```python
lambda x: (self.count_bits1(x), x)
#          ↑ 第一关键字      ↑ 第二关键字
```

对每个元素 `x`，返回一个**二元组**：

| 输入 x | bin(x) | 1的个数 | 排序键 (tuple) |
|--------|--------|---------|----------------|
| 0 | `0b0` | 0 | `(0, 0)` |
| 1 | `0b1` | 1 | `(1, 1)` |
| 2 | `0b10` | 1 | `(1, 2)` |
| 4 | `0b100` | 1 | `(1, 4)` |
| 8 | `0b1000` | 1 | `(1, 8)` |
| 3 | `0b11` | 2 | `(2, 3)` |
| 5 | `0b101` | 2 | `(2, 5)` |

#### 2. 元组的比较规则

Python 元组是**按元素顺序逐位比较**：

```python
# 先比第一位，不同就直接出结果
(1, 100) < (2, 1)     # True → 1 < 2

# 第一位相同，比第二位
(1, 2) < (1, 5)       # True → 1==1, 2 < 5
```

#### 3. 题目要求的双重排序

> 1. 按二进制 1 的个数升序
> 2. 个数相同 → 按数值大小升序

```python
arr = [8, 1, 2, 3]

# 排序键: (1,8), (1,1), (1,2), (2,3)
#            ↓   按第二关键字排   ↓
# 结果:   [1, 2, 8, 3]
#          ↑  1个1的  ↑  2个1的
```

### 对比写法

```python
# ❌ 只按 1 的个数，个数相同时顺序不确定
sorted(arr, key=lambda x: self.count_bits1(x))

# ✅ 双重排序，完美符合题意
sorted(arr, key=lambda x: (self.count_bits1(x), x))
```

## 计算二进制 1 的个数

### 方法：查表法（针对 n ≤ 10000 优化）

```python
class Solution:
    # 预计算 0-255 每个数的 1 的个数
    _BIT_COUNT = [bin(i).count('1') for i in range(256)]
    
    def count_bits1(self, n: int) -> int:
        # n <= 10000 < 2^14，最多查 2 次表
        return (self._BIT_COUNT[n & 0xFF] +           # 低 8 位
                self._BIT_COUNT[(n >> 8) & 0xFF])     # 高 6 位
```

### 为什么优化为 2 次查表？

```
10000 = 10011100010000₂  (共 14 位)
       
低 8 位: 00010000 → 1 个 1
高 8 位: 00100111 → 4 个 1
>> 16  : 0        → 恒为 0（无需查表）
```
